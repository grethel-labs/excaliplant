# Commit messages

- Inspect the staged diff or the changes the user identifies. Describe the main change a reader should find in Git history.
- Start with a short subject in the imperative mood, with no trailing period. Follow any required prefix or ticket format for the repository.
- Add a blank line and a body only when the motivation, an important behavior change or an issue reference adds context. Use a short bullet list when there are several distinct points.
