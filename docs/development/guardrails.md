# Repository guardrails

Each row describes a machine check and its failure signal. Run `npm run guardrails` for the static code and skill checks, or `npm run check` for local CI parity on formatting, types, tests and generated files.

Fails on the source line or divergent metadata. CI exercises Node 20/22/24.                                                                                                                                                                                                                                |
| Render code stays inside the rendering modules, with scoped imports for ELK, roughjs, resvg and the bundled font. [Examples](../../test/examples.test.mjs) compare scene, SVG and PNG output for repeated renders. [Preprocess](../../test/preprocess.test.mjs) checks a fixed default date.                                                                                                 |

The static suite parses source once and avoids renderer startup, subprocesses and the network. Existing CI jobs retain their runtime and packaging coverage. `npm audit --omit=dev --audit-level=high` checks production dependency advisories in CI.

Visual adequacy, useful new coverage, user-visible impact, and post-merge release verification are [review steps](guidelines.md). A new security or performance contract should include a targeted regression at the owning layer.
